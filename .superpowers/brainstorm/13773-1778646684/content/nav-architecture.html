네비게이션 아키텍처 설계

App.tsx → AuthGate → MainStack 전체 흐름

전체 네비게이션 트리
App.tsx
└── NavigationContainer + ThemeProvider
└── AuthGate (토큰 체크 → 라우팅)
├── 미인증 → AuthStack
├── LoginScreen (MockSSO — 기존 연결)
└── 인증 → MainStack
BottomTabs (컷아웃 FAB)
├── 🏠 HomeTab → RecordingListScreen (기존 연결)
├── 🔍 SearchTab → SearchScreen [신규]
├── 🎙 FAB → RecordingScreen [신규]
├── 📚 LibraryTab → LibraryScreen [신규]
└── 👤 ProfileTab → ProfileScreen [신규]
+ Stack (탭 위 푸시)
├── RecordingDetailScreen
└── TranscriptScreen

신규 화면 스펙 요약

🎙 RecordingScreen
FAB 탭 시 Modal Stack으로 진입
파형 + 타이머 + 일시정지/정지
저장 시 Bottom Sheet (제목/태그)
→ RecordingDetailScreen push
🔍 SearchScreen
autofocus SearchBar
최근 검색어 chip
결과 탭: 제목 / 본문 / 메모
결과 카드 → RecordingDetail
📚 LibraryScreen
섹션 3개: 즐겨찾기 / 보관함 / 태그
SectionList로 렌더링
태그 편집 Bottom Sheet
빈 상태 EmptyState 컴포넌트
👤 ProfileScreen
SectionList: 사용자 정보 / 보안 / 동기화 / 알림 / 데이터 / 앱 정보
로그아웃 → 확인 Bottom Sheet
authStore.logout() 호출
